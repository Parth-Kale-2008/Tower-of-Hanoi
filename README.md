# Tower of Hanoi (Java)

A simple Java implementation of the classic Tower of Hanoi puzzle using recursion. This program calculates and prints the exact steps required to move a stack of disks from a source rod to a destination rod, following the standard rules.

##  Features
- Dynamic Input:** Accepts any number of disks from the user.
- Recursive Algorithm:** efficient implementation using standard recursion logic.
- Step-by-Step Output:** clearly displays every move required to solve the puzzle.
